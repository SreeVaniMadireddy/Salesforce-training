# Day 8 - Lightning Web Components (LWC) Basics

## What is LWC?

Lightning Web Components (LWC) is a modern Salesforce framework used to build fast, reusable, and efficient user interfaces. It is based on modern JavaScript, HTML, and CSS standards.

LWC helps developers create component-based applications where each UI part can be reused independently.

---

# Why Salesforce Uses LWC

Salesforce uses LWC because:

- It provides faster performance
- It supports reusable components
- It follows modern web standards
- It improves UI maintainability
- It separates frontend and backend logic clearly
- It makes enterprise applications scalable

- Reduces duplicate code
- Saves development time

# Frontend vs Backend Thinking

## Frontend/UI Logic

Handled in UI:

- Button click actions
- Form design
- Notification display
- Input collection
- User interaction

## Backend/Apex Logic

Handled in Backend:

- Database operations
- Fee calculation
- Data validation
- Business rules
- Secure data processing

# Reflection

Modern enterprise systems use component-based UI architecture because:

- Applications become modular
- Teams can work independently on components
- Reusable UI improves productivity
- Maintenance becomes easier
- Performance becomes better
- Large applications become easier to manage

Component-based architecture helps companies build scalable and maintainable enterprise applications.

# Revision Questions

## 1. What is a component?

A component is a reusable part of a user interface that performs a specific function.

---

## 2. Why are reusable components useful?

Reusable components reduce duplicate code and improve maintainability.

---

## 3. Difference between frontend and backend?

Frontend handles user interaction and UI, while backend handles business logic and database operations.

---

## 4. Why did Salesforce move toward LWC?

Salesforce moved toward LWC for better performance and modern web development standards.

---

## 5. Why is UI important in enterprise systems?

UI improves user experience and makes applications easier to use.

---

## 6. Why should systems separate UI and business logic?

It improves security, scalability, and maintainability.

---

## 7. What security risks exist in enterprise applications?

- Unauthorized access
- Data leakage
- Weak authentication
- Improper validation

Modular thinking helps create scalable, reusable, and maintainable applications.
