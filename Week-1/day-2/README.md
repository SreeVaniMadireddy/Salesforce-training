# Day 2 - Salesforce Platform Basics

## 1. What is Salesforce Platform?

Salesforce Platform is a cloud-based platform that helps businesses manage customers, sales, services, and applications in one place. It provides tools for both admins and developers to build and customize applications.

---

# 2. App, Object, and Tab

## What is an App?

An App in Salesforce is a collection of tabs, objects, and tools designed for a specific business purpose.

Example:
Sales App, Service App

---

## What is an Object?

An Object is like a database table used to store information in Salesforce.

Examples:
Account, Contact, Opportunity

---

## What is a Tab?

A Tab is used to open and access objects and records in Salesforce easily through the user interface.

---

# 3. Difference Between Configuration and Coding

## Configuration (No Code)

Configuration means customizing Salesforce using clicks instead of programming.

Examples:
1. Creating fields
2. Creating flows and automation

---

## Coding (Apex)

Coding is used when advanced customization or complex business logic is required.

Examples:
1. Payment processing logic
2. Complex calculations

# 5. CRM Concepts in Salesforce

Account, Contact, and Opportunity are standard Salesforce objects used in CRM.

- Account stores company/customer details
- Contact stores customer/person details
- Opportunity stores sales or deal information

These objects work together inside Salesforce Apps.

---

# 6. Multi-Tenant Architecture

Multi-tenant architecture means many users and companies use the same Salesforce platform and servers securely while keeping their data separate.

---
